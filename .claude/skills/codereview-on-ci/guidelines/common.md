## 🚨 Must（このリポジトリ固有）

<!-- 例: 課金・コインの計算や表示のずれ、特定ランタイムで落ちるコード、認証フックの使い方 -->

- **ガイドラインと rules の同期（CM-01）**: `guidelines/*.md` と `.claude/rules/*.md` は同じルール ID で対応している。
  差分で次のいずれかが起きていれば Must。
  - ガイドラインのルール（🚨 Must）を追加・変更・削除したのに、対応する `.claude/rules/*.md` が同じ PR で直っていない
  - `.claude/rules/*.md` のルールを追加・変更・削除したのに、対応するガイドラインが同じ PR で直っていない
  - ルールの内容を変えたのに ID が据え置かれている（内容を変えたら新しい ID を振り、旧 ID を両側から消す）
  - rules に、ガイドラインに存在しない ID がある
  確認のしかた: 差分に含まれる ID を両ファイルで Grep し、もう一方に同じ ID と同じ趣旨があるかを見る。
  例外: 文言の言い換えだけで判定と内容が変わらない変更は ID を変えなくてよい（💭 Nit にもしない）
